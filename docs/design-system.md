# Design system

Premium atelier / circular-wardrobe storefront — uncluttered, product-first.

## Direction

- Expressive typography (not default Inter/system stacks for display).
- Atmosphere via soft gradients / texture; avoid flat single-color fields as the only surface.
- Full-bleed hero on promotional surfaces; brand name as a hero-level signal.
- Cards only when they contain interaction; no card chrome in the hero.
- One job per section: one headline, one short support line.

## Avoid

Purple-on-white AI defaults, cream+terracotta clichés, broadsheet hairline denseness, emoji clusters, pill strip clutter.

## Components

shadcn/ui primitives under `src/components/ui`. Storefront chrome in `src/components`.
